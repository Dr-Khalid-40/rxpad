🧩 Prescription templates

A template stores everything except the patient's name and ID — complaints, history, signs, diagnosis, medicines, investigations and advice. Build a case on the Write Rx page, then use "Save as template" in the bottom bar. Loading a template fills the form; you then add the patient's details and save it as a normal prescription.

The assistant works offline out of the box using the built-in knowledge base. If you want richer, free-text reasoning, paste an Anthropic API key from console.anthropic.com — it stays on this computer only. Leave blank to stay fully offline.

☁️ Cloud sync (Supabase)

Your data automatically syncs to the cloud every time you save anything. Works on every device — phone, tablet, laptop — no setup needed. To use the same data on a new device, copy your Device ID and paste it there.

☁️ Sync via Google Drive folder

There's no real Gmail sign-in here — but Chrome can save your data straight into a file inside your Google Drive desktop folder, and Drive will sync that file to the cloud and to your other devices automatically. This needs the free Google Drive for desktop app installed and signed in on this computer first.
